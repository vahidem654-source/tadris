نصب روی GitHub Pages:
1) یک مخزن (repository) جدید بساز.
2) شش فایل index.html, board.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png را در ریشهٔ مخزن آپلود کن.
3) Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4) بعد از یکی دو دقیقه آدرس https://USERNAME.github.io/REPO/ آماده است.
5) روی گوشی و کامپیوتر باز کن و Install app / Add to Home Screen بزن.
نکته: اگه فایل‌ها را عوض کردی، در sw.js مقدار V را (مثلاً slide-v2) تغییر بده تا کش به‌روز شود.

فونت بی‌نازنین: فایل BNazanin.ttf را کنار index.html در مخزن بگذار (اختیاری؛ مسئولیت مجوز فونت با خودت است).
